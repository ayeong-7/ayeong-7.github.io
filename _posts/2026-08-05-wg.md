# 1. carve party
## 문제  
할로윈 파티를 기념하기 위해 호박을 준비했습니다! 호박을 10000번 클릭하고 플래그를 획득하세요!

## 풀이  
10000번 클릭할 수도 있겠지만, 좀 더 편하게 풀기 위해서 코드를 보면, `$('#jack-target').click()` 함수가 counter의 값을 늘려주는 것을 알 수 있다. counter 변수에 호박을 클릭한 값이 담기는 것으로 보여 counter을 10000으로 바꾸면 되겠다는 결론을 내렸고, 콘솔에 counter=10000을 입력해 보았는데, Ip;ISdiK;... 같은 이상한 문자열이 나왔다. 그래서 counter의 값을 늘려주는 `$('#jack-target').click()` 함수를 10000번 반복하면 되겠다는 생각을 했고, 
```
for(i=0; i<10000; i++)	
    {$('#jack-target').click()}
```
을 콘솔창에 입력했더니 FLAG인 DH{I_lik3_pumpk1n_pi3} 가 나왔다.  

## 답 : DH{I_lik3_pumpk1n_pi3}


# 2. flying chars
## 문제  
날아다니는 글자들을 멈춰서 전체 문자열을 알아내세요! 플래그 형식은 DH{전체 문자열} 입니다.
❗첨부파일을 제공하지 않는 문제입니다.
❗플래그에 포함된 알파벳 중 x, s, o는 모두 소문자입니다.
❗플래그에 포함된 알파벳 중 C는 모두 대문자입니다.

## 풀이  
방법은 2가지가 있는데, 첫 번째는 javascript 맨 윗 줄에 있는 /static/images/10.png 이 사진 파일의 숫자 순서대로 조합하면 FLAG를 얻을 수 있다. 두 번째는 anim() 함수를 보면, anim(elem(요소), pos(위치), dis(이동할 값))와 move() 함수가 정의되어 있는 것을 볼 수 있는데, 여기서 dis 부분을 0으로 만들면 움직임을 멈출 수 있다. 따라서 콘솔에 
```
for(var i =0; i <20; i++)
    {anim(imgs[i], 0, 0)} 
```
을 입력하면 맨 왼쪽에 글자들이 멈추게 되고, 이를 위 문제에 있는 규칙에 따라 작성하면 FLAG인 DH{Too_H4rd_to_sEe_th3_Ch4rs_x.x} 를 얻을 수 있다.  

## 답 : DH{Too_H4rd_to_sEe_th3_Ch4rs_x.x}


# 3. simple-web-request
## 문제  
STEP 1~2를 거쳐 FLAG 페이지에 도달하면 플래그가 출력됩니다.
모든 단계를 통과하여 플래그를 획득하세요. 플래그는 flag.txt 파일과 FLAG 변수에 있습니다.
플래그 형식은 DH{...} 입니다.

## 풀이  
app.py를 열고 step1() 함수를 보면
```
if request.method == "GET":
        prm1 = request.args.get("param", "")
        prm2 = request.args.get("param2", "")
        step1_text = "param : " + prm1 + "\nparam2 : " + prm2 + "\n"
        if prm1 == "getget" and prm2 == "rerequest":
            return redirect(url_for("step2", prev_step_num = step1_num))
        return render_template("step1.html", text = step1_text)
    else: 
        return render_template("step1.html", text = "Not POST")
```
prm1이 getget 이고, prm2가 rerequest 일 때, step2로 리다이렉션 되도록 설계 되어있으므로, step1의 
param=getget&param2=rerequest이다. 이렇게 입력하면 step2로 넘어가게 되는데, 이번에는 flag() 함수를 살펴보면,
```
                prm1 = request.form.get("param", "")
                prm2 = request.form.get("param2", "")
                if prm1 == "pooost" and prm2 == "requeeest":
                    return render_template("flag.html", flag_txt=FLAG)
                else:
                    return redirect(url_for("step2", prev_step_num = str(step1_num)))
            return render_template("flag.html", flag_txt="Not yet")
        except:
            return render_template("flag.html", flag_txt="Not yet")
```
prm1이 pooost, prm2가 requeeest 일 때, flag 파일을 렌더링한다고 되어있다. 따라서 step2에 param=pooost, param2=requeeest 를 입력하면 FLAG인 DH{c46b414ddba26adfa4606c59655bda0a18fbe260606b042b52d865e0160eea0e}를 얻을 수 있다.  

## 답 : DH{c46b414ddba26adfa4606c59655bda0a18fbe260606b042b52d865e0160eea0e}
